# Abastecimento

Aplicativo mobile desenvolvido em **Flutter** para registrar e acompanhar abastecimentos de veículos.

## Funcionalidades

* Cadastrar abastecimentos
* Visualizar histórico
* Editar registros
* Excluir abastecimentos
* Calcular preço médio por litro
* Calcular consumo médio em km/L
* Salvar os dados localmente
* Alternar entre tema claro e escuro

## Tecnologias

* Flutter
* Dart
* SharedPreferences

## Dados cadastrados

Cada abastecimento possui:
* Data
* Combustível
* Litros
* Valor pago
* Quilometragem

## Como executar
Instale as dependências:

```bash
flutter pub get
```

Execute o aplicativo:

```bash
flutter run
```
